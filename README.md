# Tokyo Rail Map

実際の地理形状（区市町村境界・駅の緯度経度）に基づいた、東京都のインタラクティブ鉄道路線図です。JR・東京メトロ・都営地下鉄・私鉄各線を1枚のSVG地図上に表示します。

## 使い方

`index.html` をブラウザで開くだけで動作します（ビルドや依存関係のインストールは不要です）。GitHub Pages等でそのまま公開する場合もこのファイル名でルートに配置してください。

- **路線の表示切替**: 左サイドバーの路線名をクリック（またはフォーカスして Enter/Space）
- **全ON / 全OFF**: サイドバー上部のボタン
- **パン**: 地図をドラッグ
- **ズーム**: マウスホイール、ピンチ操作、または右下の ＋ / － ボタン
- **表示リセット**: 右下の ⌂ ボタン
- **線の太さ調整**: ヘッダー右上のスライダー
- **駅名の確認**: 駅（ドット）にマウスオーバー

## 構成

単一の自己完結型HTMLファイルです。区市町村境界データ（`DISTRICTS`）と路線・駅データ（`OPERATORS`）をJSONとしてインラインで保持し、読み込み時にSVG要素として描画します。
